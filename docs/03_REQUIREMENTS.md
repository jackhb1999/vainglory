## 1. 产品定位

**一句话**：一款原创世界观的桌面/移动端 3v3 团队竞技游戏，以单条主道 + 侧翼林隙、占领型中立目标、双出装构筑，支持**鼠标点触自动寻路**（v1.3 起为唯一移动方式，键盘 W/A/S/D 不再移动），提供 18±4 分钟（硬上限 25 分钟）一局的高操作深度对局。

| 维度 | 定义 |
|---|---|
| 目标用户 | 有 MOBA 经验、追求操作深度与短时长对局的移动端玩家（16+） |
| 核心乐趣 | 补刀与对线博弈、林隙遭遇战、中立目标争夺的团队决策、出装构筑带来的同英雄差异化 |
| 差异化 | 3v3 单线（低认知负荷、短对局）+ 占领型目标（非纯推塔节奏）+ 刃能/秘能双构筑 |
| 商业模式 | F2P；仅外观与便利类付费，**不售卖数值优势**（CR-04） |
| 一期平台 | 桌面端用于验证；目标平台为移动端正版渠道（Android 先行），单区域 |
| 明确非目标 | 见 §3 |

> **名称**：`GX-01` 是内部工程代号，不是产品名。产品名与 Logo 须经商标 FTO 检索后由市场/法务确定（CR-01）。

### 1.1 规则层借鉴与表达层原创的边界（强制）

| 借鉴（仅规则） | GX-01 原创表达 |
|---|---|
| 3v3、单主道 + 野区 | 灰界裂谷、主道/林隙、原创地形与景观 |
| 占领型中立目标 | 辉矿 / 征募井 / 渊卫（原创命名、原创模型、原创机制细节与数值） |
| 双出装体系 | 刃能 / 秘能（原创属性名、原创装备树、原创数值） |
| 点触操作 | 原创交互布局与手势规范：左键点地自动寻路、右键立即移动/锁定普攻；**不提供键盘或虚拟摇杆移动**（`GX-CBT-2026-001` §3） |
| 约 20 分钟节奏 | 18±4 分钟，由 GX-01 自研经济曲线与阶段规则实现 |

**所有数值均为 GX-01 自研，必须从 `ConfigSet` 读取，禁止引用任何原作公开数值表或遥测字典**（`GX-ARCH-2026-001` DN-23 / DN-29）。术语与禁用词见架构 §2。

## 2. 用户与场景

| ID | 角色 | 场景 |
|---|---|---|
| UC-01 | 新玩家 | 首次进入，完成引导，理解左键寻路 / 右键移动与锁定普攻、推塔目标，在 10 分钟内打完第一局 |
| UC-02 | 对线玩家 | 在主道补刀、消耗、呼叫游猎支援，通过出装建立优势 |

| UC-10 | 合规/审计人员 | 核验实名、防沉迷、付费限额、资产来源与禁词 |

## 3. 范围

### 3.1 一期交付（V1.0）
1 张地图、3v3 单模式、12 位英雄、完整对局闭环、装备与商店、双操作模式、账号与合规、匹配与排位、反作弊基础、运营后台、回放与遥测、产品级 UI。

### 3.2 垂直切片（V0.1，M2）
1 张地图、3 位英雄、完整一局（生成→对线→目标→摧毁源核→结算）、基础商店、基础 UI、单机/局域可跑、**产出单局服务器成本实测值**。切片不包含账号、支付、匹配、多平台。

### 3.3 明确非目标（Out of Scope）
| 项 | 理由 |
|---|---|
| 5v5 三路地图 | 实体数与服务器成本翻倍，同质化竞争激烈（上游 §6.3） |
| 真实视线迷雾（视线级） | 一期已做草丛/遮蔽的简化可见性 + 客户端三档迷雾渲染（P-U10，可见源圆盘 + 已探明记忆）；完整 LoS（墙体遮挡）仍属二期 |
| 全球多区域同服 / 跨平台输入公平性 | 单位经济未验证前不扩张 |
| Web(wasm) 客户端 | `renet2_netcode` 依赖原生 UDP，需另做传输实现（ADR-04 保留能力） |
| 自建电竞赛事体系 | 生态窗口已关闭（上游 §2.9） |
| 皮肤量产、主机平台 | 内容成本与周期 |
| 原作任何名称、角色、地图、音乐、UI、数值 | 法律禁止（上游 §3） |

|---|---|

| 优先级 | 含义 |
|---|---|

## 10. 验收总则

1. 每条 P0/P1 需求必须有至少一个自动化 `TC-*` 用例或明确的手动验收脚本；
2. 验收数据必须来自权威服务端或回放，不以客户端显示为准；
3. 所有 CR 项在发布清单中逐条签字；
4. NFR 指标由压测/机型实测报告支撑，不接受"目测流畅"；
5. 需求变更须同步更新本文档、架构追溯矩阵与开发任务卡，禁止只改代码。
